Modifikasi Aplikasi Flutter

Pada aplikasi ini dilakukan modifikasi dari fitur dasar yang sebelumnya hanya memiliki fungsi penambahan nilai. Modifikasi dilakukan untuk meningkatkan fungsionalitas dengan menambahkan fitur pengurangan dan reset nilai.

--Perubahan yang Dilakukan--
1. Penambahan Fungsi Decrement
2. Ditambahkan method untuk mengurangi nilai counter.
3. Penambahan Fungsi Reset
4. Ditambahkan method untuk mengembalikan nilai counter ke nilai awal (0).
5. Memudahkan pengguna untuk mengulang perhitungan tanpa harus mengurangi nilai secara manual.

Floating Action Button dikembangkan menjadi beberapa tombol:
Tombol (+): untuk menambah nilai counter
Tombol (-): untuk mengurangi nilai counter
Tombol (reset): untuk mengembalikan nilai ke 0
Tombol-tombol ditampilkan berdampingan agar lebih mudah diakses.
